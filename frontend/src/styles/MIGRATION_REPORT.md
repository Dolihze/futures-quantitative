## 迁移技术方案

### 1. 样式提取
将每个Vue组件的 `<style scoped>` 块中的CSS代码提取到独立的 `.css` 文件中。

**迁移前（Vue组件）**:
```vue
<style scoped>
.container {
  /* 大量样式代码 */
}
</style>
```

**迁移后（Vue组件）**:
```vue
<style scoped>
@import '@/styles/组件名.css';
</style>
```

### 2. 样式隔离机制
- **Vue Scoped CSS**: 保持原有的作用域隔离机制
- **类名唯一性**: 各页面使用独立的类名空间
- **CSS Modules**: 未启用（保持现有开发体验）

### 3. 文件组织
```
frontend/src/styles/
├── index.css          # 全局样式入口（可选使用）
├── Trading.css        # 交易页面样式
├── Home.css           # 首页样式
├── Backtest.css       # 回测页面样式
├── Login.css          # 登录页面样式
└── README.md          # 样式目录说明
```

## 使用指南

### 开发新功能时
1. 在 `src/styles/` 目录下创建对应的CSS文件
2. 在Vue组件中使用 `<style scoped>` 引入该CSS文件
3. 遵循 `README.md` 中定义的命名规范

### 修改现有样式时
1. 找到对应页面的CSS文件（如 `Trading.css`）
2. 直接在CSS文件中修改样式
3. 保存后，Vite会自动热更新

### 调试样式时
1. 使用浏览器开发者工具定位元素
2. 查看Computed面板，确认样式来源
3. 在对应的CSS文件中进行修改
