# 量化回测功能使用说明

## 功能概述

量化回测功能允许用户获取期货合约的历史K线数据，并进行可视化展示和技术分析。

## 当前支持

- **合约**: 燃料油FU2611
- **数据周期**: 1分钟、5分钟、15分钟、30分钟、60分钟
- **数据范围**: 近7天、近30天、近60天、近90天

## 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动程序

```bash
python app.py
```

### 3. 访问回测页面

1. 登录系统（可使用测试账号：admin/123456）
2. 在首页点击"量化回测"卡片
3. 在左侧面板选择参数：
   - 合约代码：FU2611
   - 数据周期：1分钟（默认）
   - 数据范围：30天（默认）
4. 点击"加载数据"按钮

### 4. 图表操作

- **缩放**: 使用鼠标滚轮或拖动滑块
- **查看详情**: 鼠标悬停显示OHLC数据
- **调整范围**: 拖动底部滑块选择查看范围

## 数据来源

数据来源于新浪财经，通过akshare库获取，保证数据真实精确。

## 注意事项

1. 确保网络连接正常
2. 数据加载可能需要几秒钟
3. 如果在非交易时间获取数据，可能获取到的是最近一个交易日的数据
4. 1分钟数据量较大，建议首次加载时选择较小的数据范围

## 依赖说明

- `akshare`: 用于获取期货历史数据
- `pandas`: 数据处理
- `flask`: Web框架
- `pywebview`: 桌面应用窗口
